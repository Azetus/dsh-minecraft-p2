- Vanilla 1.21.1，LAN `127.0.0.1:25575`

## 结论

- **look**：yaw 从 0 到 1.5708，pitch 到 0.199，视角控制生效。
- **move**：前进 3.23 格，方向与 yaw 一致；y 有 0.0625 的地形/落地修正。
- **jump**：最大高度从 -60.0625 到 -58.8133，约 1.25 格；`airborne=true`，跳跃生效。
- **stop**：`clearControlStates` 后所有控制位为 false；停止后第一秒残余 0.0337 格，随后一秒为 0，水平速度为 0。
- 人类 `Human_Player` 与 P2 同时在线；没有执行攻击/挖掘/放置。
- 生命/饥饿保持 20/20。

## 注意

- 停止第一秒仍有约 0.03 格的位置修正，不能当作严格零延迟；G3 需要从外部命令/runner 层面测停止，并记录 stop 后动作计数。
- 这仍是 Mineflayer 原始控制，不是 P2 ControlOp/broker 契约；下一步应把 look/move/jump/stop 映射到 P2 的 act 与 stop 路径。
- 世界仍有被动实体/铁傀儡，虽然 peaceful；G2 后续保持在测试区，不靠近村民/铁傀儡。
